5.3 · Input/Output Response

Steady-State Response

Given a linear input/output system, the output can be computed for any input using the convolution equation. In practice, we are often interested in the response to sinusoidal inputs, since many signals can be decomposed into a sum of sinusoids through Fourier analysis.

The frequency response of a stable system is characterized by its gain and phase at each frequency, which together describe how the system amplifies and shifts a sinusoidal input once transients have decayed.

y(t) = M sin(ωt + θ),   M = |G(iω)|,   θ = arg G(iω)

The gain M and phase θ can be plotted as functions of frequency, giving the Bode plot, which we will study in detail in Chapter 9…

# Second principe

L'entropie $S$ est une fonction d'état.
Pour une transformation réversible :

$$dS = \frac{\delta Q_{rev}}{T}$$

> L'entropie d'un système isolé ne peut que
> croître ou rester constante.
> — [[@cengel2019, p. 411]]

## Inégalité de Clausius

$\oint \frac{\delta Q}{T} \le 0$ · voir [[Cycle de Carnot]]

## À retenir
| Cas | $\Delta S$ |
|---|---|
| Réversible | $= 0$ |
| Irréversible | $> 0$ | #examen
